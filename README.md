# PodCLI

A terminal-based podcast manager and player built with Python. `podcli` allows you to manage your favorite podcast feeds, download episodes for offline listening, and enjoy an interactive playback experience directly from your command line.

## Features

- **Add Podcasts**: Simply provide an RSS feed URL to add a new podcast to your library.
- **Interactive Search**: Fuzzy search through your subscribed channels and episodes.
- **Offline Listening**: Automatically downloads episodes for playback and stores them locally.
- **Terminal Player**: Rich-text playback interface with progress bars and time displays.
- **Local Database**: Uses a lightweight local database (dbm) to track your subscriptions and episode metadata.

## Prerequisites

- Python 3.13 or higher
- [uv](https://github.com/astral-sh/uv) (recommended for dependency management)

## Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/yourusername/podcli.git
   cd podcli
   ```

2. Install dependencies using `uv`:
   ```bash
   uv sync
   ```

## Usage

To start the application, run:

```bash
uv run main.py
```

### Main Menu

Upon launching, you will be presented with three options:
- **Listen**: Browse your added podcasts and select an episode to play.
- **Add**: Paste an RSS feed URL to add a new podcast to your collection.
- **Exit**: Close the application.

### Podcast Player Shortcuts

When listening to an episode, use the following keys to control playback:

| Key | Action |
|-----|--------|
| `Space` | Play / Pause |
| `Right Arrow` | Skip forward 30 seconds |
| `Left Arrow` | Skip backward 30 seconds |
| `Q` | Stop playback and return to menu |

## Project Structure

- `main.py`: Entry point and main CLI loop.
- `podcli.py`: Core logic for downloading episodes and the interactive player.
- `db_operations.py`: Handles local storage of podcast and episode metadata using `dbm`.
- `utils.py`: Utility functions (e.g., time formatting).
- `downloads/`: Directory where downloaded podcast episodes are stored.

## Dependencies

- [feedparser](https://github.com/kurtmckee/feedparser): For parsing RSS feeds.
- [httpx](https://github.com/encode/httpx): For downloading audio files.
- [InquirerPy](https://github.com/kazhala/InquirerPy): For interactive terminal menus.
- [just-playback](https://github.com/cheofusi/just-playback): For audio playback.
- [rich](https://github.com/Textualize/rich): For beautiful terminal UI and progress bars.
- [typer](https://github.com/tiangolo/typer): For building the CLI interface.
